## Adopted optimization

`stale-context-guards` adds one independently switchable behavior: mutations
must be based on current state when concurrent or external change is plausible.
Native hashes, versions, ETags, anchored patches, or compare-and-swap are
preferred. Every harness has the fallback of re-reading the smallest relevant
region immediately before mutation. Failed preconditions cause refresh and
reconciliation, never a forced or blind retry.

### Expected benefit

- Accuracy: prevents an edit generated from old state from overwriting newer
  user, tool, or agent changes.
- Tokens: avoids string-not-found loops, repeated failed patches, and long
  recovery conversations; the narrow-refresh fallback limits added read cost.
- Safety: preserves unrelated concurrent changes and turns divergence into
  explicit evidence.

These are mechanisms, not measured LAMF benchmark results. Cross-harness
isolation and package tests are the acceptance evidence for this release.

## Portability decision

The module is an instruction fragment distributed by LAMF's universal MCP
launcher. It requires no Hashline package, Bun runtime, network service, model,
provider, editor, or native patch format. Codex, Claude, Kimi, Grok, OpenClaw,
Hermes, and generic MCP clients receive the same invariant; clients with native
preconditions use them and all others use the bounded re-read fallback.
