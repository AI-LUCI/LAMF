# Verified Execution

1. Express completion as observable outcomes before changing state.
2. Reproduce or diagnose current behavior when applicable.
3. Select the smallest checks that cover the relevant risk.
4. Implement and repeat the checks until they pass.
5. Distinguish verified facts, reasonable inferences, and untested areas.
6. Stop only on completion or a concrete blocker.

Read [references/provenance.md](references/provenance.md) only when evaluating or updating this optimization.
